# 📊 Advanced Data Visualizations with Python

This project demonstrates various **advanced data visualization techniques** using Python libraries such as **Matplotlib**, **Seaborn**, and **Pandas**. The goal is to explore and interpret data through visual patterns to support data-driven decisions.

---

## 🔍 What’s Inside

- Univariate and Bivariate Visualizations
- Histograms, Boxplots, and Violin Plots
- Correlation Heatmaps
- Pair Plots for multivariate analysis
- Outlier detection through visuals
- Plot styling and customization

---

## 🛠️ Tools & Libraries Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📁 Files Included

- `EDA_Cleaned.ipynb` – Jupyter Notebook with code and visual output
- `EDA_Cleaned.pdf` – PDF version of the notebook for easy viewing
